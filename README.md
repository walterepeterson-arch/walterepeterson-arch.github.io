# Walter Eric Peterson — Personal Portfolio

A responsive portfolio with an integrated Airline Corner learning area.

## Files

- `index.html` — main personal portfolio page.
- `style.css` — portfolio styling and responsive layout.
- `script.js` — mobile navigation and Airline Corner interactions.
- `airline-corner.html` — learning academy page.
- `training-question-bank.js` — quiz questions for beginner, intermediate and advanced levels.
- `walter.png.jpg` — profile photograph. Keep this image in the repository root.

## Install on GitHub

1. Open your repository:
   https://github.com/walterepeterson-arch/walterepeterson-arch.github.io
2. Upload or replace the six text files listed above in the repository root.
3. Keep your existing `walter.png.jpg` file in the root.
4. Commit the changes. GitHub Pages will publish the updated site.

## Important

The Amadeus-style terminal is a demonstration only. It is not connected to a live reservation system. Airline policy, fares, baggage, ticketing and operational information should always be checked against current official sources.

Learning progress is saved in the visitor's browser using local storage. It is not synced between devices.
